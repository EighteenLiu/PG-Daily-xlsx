# 台账处理与拆分系统

Windows 桌面程序，按项目开发文档实现：

1. 上传原始台账，仅支持 `.xlsx`；`.xls` 需由用户先自行转换为 `.xlsx`。
2. 删除指定字段并调整列顺序生成基础台账。
3. 预览、导出、重新上传基础台账。
4. 删除“具体问题”为“无问题”的记录生成问题台账。
5. 预览、导出、重新上传问题台账。
6. 根据问题台账生成居民自主投放表。
7. 根据问题台账更新《小区村值守率及投放准确率统计.xlsx》。
8. 按“2级点位 + 3级点位”拆分。
9. 导出全部 Excel，默认输出 `.xlsx`。

说明：原始台账转基础台账时，“编号/序号”列会按当前数据行重排为 `1, 2, 3...`。图片按所在数据行和图片字段列跟随筛选、列移动和拆分导出，保持原始图片宽高。居民自主投放表仅按 `2级指标 == 居民自主投放` 筛选，不查看“具体问题”列。准确率统计表会更新日期和“投放准确率”分组下的投放错误数；如果问题台账中的小区/村居在统计表中不存在，会按“小区/村居”追加到对应 Sheet 末尾，并写入街镇、社区/村、小区或村居名称、日期、投放总数 10、投放错误数。导出的台账文件使用宋体、居中、自动换行，前两行表头加粗并按分组合并，数据行高为 63 磅。

## 运行

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

## 打包

```powershell
python build_release.py
```

生成文件位于 `dist/台账处理与拆分系统.exe`。
